# cgraph — prototype → production log

Corners cut to keep the prototype moving, and what production needs instead.
Add to this whenever you trade correctness/completeness for speed. Nothing here
should be promoted from `research/` into `src/saeco/` until its row is resolved
or consciously accepted. Started 2026-06-01.

| # | Corner cut (prototype) | What production needs | Status |
|---|------------------------|------------------------|--------|
| 1 | **Node naming is auto `n#`** when not bound to a class attr. | Stable, meaningful names — they become `state_dict` keys and cache paths. A rename/reorder must not silently break checkpoints. Nested-namespace naming (#2) + a defined key scheme. | open |
| 2 | **Same module instance as producer of 2+ nodes** (weight tying via templates) would `add_module` it under two names → duplicated `state_dict` entries. | Detect shared module instances and register once / alias, or define tying semantics explicitly. | open |
| 3 | **Node-output writes `cache._write(name, out)` are unwatched** (node names aren't declared cache fields) — tracked in `_unwatched_writes`, not stored. Harmless, BUT a node named like a watched field (`L1`,`L0`,`loss`,`sparsity_penalty`,`cosim`,`L2_loss`) would hijack that slot. | Collision-safe namespacing for node-output writes (e.g. write under a reserved subcache, or skip/guard against watched names). Penalties/metrics themselves write watched fields into their own subcaches and ARE stored + found correctly. | resolved (mechanism understood); collision-guard open |
| 4 | ~~Losses may expect a nested cache tree the graph can't produce.~~ **Resolved:** the executor passes `cache[name]` to each module node, preserving the real nested subcache tree; `SparsityPenaltyLoss.search("sparsity_penalty")` finds penalties regardless of graph shape. Validated in `trainable_spike.py`. | — | resolved |
| 5 | **Seq/Parallel/Router not reimplemented on Graph.** Coexist for now. | Optional: unify them as fixed-wiring graphs, or keep both deliberately. Decide before claiming "one abstraction". | open |
| 6 | **Type-checker story for `Arg`/templates** not designed. | If `Arg` is adopted, `g(...)`'s `Ref`-vs-`Template` return must stay checker-visible (the whole point of avoiding a traced DSL). | open (gated on Arg decision) |
| 7 | **Integration with resampler / save-load / sweeps unverified.** Graph is a `cl.Module` so it *should* introspect, but the resampler's module-walking and the descriptor system haven't been run against a Graph. | Run a real architecture (#3) through resample + save/load + a sweep. | open |
| 8 | **Error quality is partial.** Cycle detection + duplicate-name + (TODO) arity-mismatch on op nodes. | Fail-fast with clear messages at every boundary (arity, unbound `Arg`, missing input, dangling ref across GraphDefs). | partial |
| 9 | **`Graph.forward` rebuilds a `results` dict each call**; fine, but no attempt at in-place / compiled execution. | Confirm no perf regression vs Seq on a real model; consider `torch.compile` compatibility. | open |
| 10 | **Loss layer re-runs the model per loss** (`Loss.__init__` wraps it in `ReuseForward`; `Loss.forward` calls `self.module(x, cache)`), relying on the root cache's `forward_reuse_dict` to dedup across loss calls (incl. shared computation between main and aux models) so the penalty fires once. A graph model has no cross-call memo → naive per-loss re-run double-counts (shown in `trainable_spike.py`). | **The total loss is ONE fused DAG**: main + aux + penalties + per-loss math + weighted sum, sharing nodes (e.g. the encoder) so dedup is by node identity (validated in `megaloss_spike.py`). Kills the cross-call ReuseForward AND retires `cache.search` (penalty = value edge) + implicit detach (explicit edges). | **design validated; not yet built into real Loss/Trainable** |
| 13 | **Fusion dedups only by node identity.** Opaque `Graph`-as-a-node does NOT fuse (encoder runs 2× under naive separate-`GraphDef` nesting). | **Implemented: hash-consing at construction** (`core.py`) — `g(producer,*inputs)` returns an existing equivalent node, so subgraphs sharing one builder fuse automatically (`fusion_spike.py`). Purity opt-out via `fresh=True`. Production: decide the impure-producer policy (explicit `fresh=` vs an `impure` marker on stateful/stochastic modules), and whether to also offer an inline+CSE pass for already-frozen graphs (prefer not to need it). | mechanism done; purity policy + emitter-descriptor wiring open |
| 15 | **Hash-consing assumes producer purity.** A stateful/stochastic module (EMA tracker, dropout, noise) called twice with the same input would be merged to one execution — changes semantics. (Same hazard `ReuseForward` already has, but now it's automatic.) | Require `fresh=True` (or an `impure` flag) for such producers; consider detecting/erroring when an impure-marked module would be consed. | open |
| 14 | **Penalties-as-value-nodes vs existing `search`-based losses.** Spike wires penalty value along an edge; real `SparsityPenaltyLoss` uses `cache.search`. | Migrate real losses to consume penalty value nodes (or keep `search` as a bridge). Decide `num_expected`>1 aggregation as an explicit sum node. | open |
| 11 | **`MockTrainable` skips `Trainable.__init__`** — so no `encode_only`/`decode_only`, no `normalizer.input_normalize` wrapping of losses, no auto metrics/`CosineSimilarityLoss`/`L2Loss`, no resampler; `loss()` returns a scalar but bypasses input-normalization and runs once. | Reconcile with the real `Trainable` contract: `rearrange`/`dearrange`, metrics, coeffs from `train_cfg`, resampler hookup, and decide where normalization lives (in the model graph vs. wrapping losses). | open |
| 12 | **Loss compares in original (denormalized) space** — the io-normalized model output vs raw `x`. Production wraps losses in `input_normalize` and compares in normalized space. | Decide the loss space deliberately (data-space vs normalized-space objective) when integrating with real losses. | open |
| 16 | **Dedup-vs-override tension** (`dedup_test.py`). Consing keys on producer *identity*: two distinct `nn.ReLU()` instances don't dedup though semantically equal, so identical slot *defaults* recompute. Sharing the instance dedups but couples the slots (one identity → can't override independently). | Guidance for authors: use a function ref (`torch.relu` — dedups by fn id) or share the instance for genuinely-shared parts. Framework options: a canonicalization pass for parameter-free producers (key by type+config), opt-in so it doesn't fight intentional distinct slots; and/or warn on likely-accidental redundancy (distinct param-free instances, same config + input). | open (design) |
